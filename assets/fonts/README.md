# Custom Font Assets

To use the premium **Aalto Display Font** on this website, follow these simple steps:

1. Download the font files from your Gumroad purchase page.
2. Put the font files in this folder (`assets/fonts/`).
3. Make sure the files are named exactly:
   - `Aalto-Display.otf` (for OpenType format)
   - *and/or* `Aalto-Display.ttf` (for TrueType format)
   - *and/or* `Aalto-Display.woff2` / `Aalto-Display.woff` (for Web formats)

Once you place the files in this directory, the website will automatically load and apply the **Aalto Display** font to all headlines, titles, and display elements.

*Note: While the files are missing, the website uses **Syne** as a beautiful, premium fallback display font so that the site continues to look amazing!*
